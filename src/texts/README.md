# Тексты бота

Всё, что бот пишет участникам, лежит здесь — как переводы: каталог по ключам, а стиль — как язык. Панель организатора и журнал турнира сюда не входят, у них один стиль.

- `base/` — основной стиль. В нём есть все тексты, по разделам: регистрация, сбор песен, пары, матч, финал, команды, выход, события турнира.
- `rude/` — ругательный стиль в духе Куно из Disco Elysium; `disco/` — голоса навыков из той же игры («ВНУТРЕННЯЯ ИМПЕРИЯ — …»), список голосов и их характер — в `disco/index.ts`. Стиль участник выбирает командой `/style`. Стиль переопределяет только то, что хочет; чего в нём нет — берётся из основного. Новый текст достаточно написать один раз в `base/`.
- `index.ts` — список стилей и выбор текстов для человека.

## Как устроена запись

```ts
closed: 'Сбор уже закрыт',                                   // просто строка
hello: ({ name }) => `Привет, ${name}!`,                     // строка с параметрами
thanks: pickWith<{ total: number }>('Спасибо!', 'Спасибо за песни!'), // варианты (в base/)
```

В стиле те же ключи, а вместо строки можно дать список вариантов:

```ts
closed: ['Сбор закрыт, всё.', 'Поздно, сбор уже закрыт.'],
hello: [({ name }) => `Здорово, ${name}!`, ({ name }) => `О, ${name}!`],
```

Какой вариант выпадет, зависит от того, кому бот пишет, и от содержимого сообщения: то же сообщение при перерисовке не меняется, а разные — звучат по-разному. Пустая строка в списке — «ничего не добавлять».

Параметры — те же, что в основном стиле: их подставляет код. Если в основном стиле фраза без параметров, в стиле она тоже без них.

## Тон

Основной стиль — человечный и спокойный, чуть тёплый, без панибратства и шуток. Изредка у фразы есть варианты, чтобы бот не звучал как автомат.

Правила для всех стилей:

- **С участником — на «ты»**, без рода: не «ты вышел», «сам», «готов», а «ты больше не в турнире», «выберешь ты», «ты на месте». Про организатора — тоже без «он»: «по решению организатора».
- **Бот говорит от себя** («получил», «пришлю»). Вводное к сбору — от организаторов, на «мы», а о боте там — в третьем лице. В ругательном стиле бот всегда говорит о себе в третьем лице: «Ботик получил», «Ботик такое уже видел» — никогда «я».
- **Смысл и цифры не трогать.** Номер матча, имена, сроки, счёт, что нажать дальше — всё должно остаться. Стиль меняет подачу, не содержание.
- **Кнопки и подсказки согласованы.** Если стиль переименовал кнопку, текст, который на неё ссылается («нажми «Начать трек»»), должен назвать её так же.
- **Мат — только в ругательном стиле**, и он про ситуацию, песни и самого бота, а не про человека: никаких оскорблений внешности, происхождения и т. п. Задираться по-дружески можно («хуль ты тыкаешь?»), проигравшего не унижаем. Наркотики и алкоголь, в отличие от Куно, не упоминаем.
- **Коротко.** Сообщения читают на телефоне посреди игры.

## Новый стиль

1. Папка `src/texts/<id>/` с `index.ts`: название для кнопки, пример фразы и тексты (`Style` из `../index.ts`). Если стиль не для всех (мат и т. п.), добавь `warning` — что ждёт человека: тогда перед включением бот покажет его и спросит подтверждение.
2. Добавить его в `STYLES` в `src/texts/index.ts`.
3. `npx vitest run src/texts` — тест прогоняет все фразы всех стилей.
