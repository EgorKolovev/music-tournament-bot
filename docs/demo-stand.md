# Демо-стенд

Веб-симулятор бота для показа решения. Колонки — чаты участников с ботом: те же сообщения и кнопки, что бот отправит в Telegram. Справа — что бот знает внутри: библиотека, сетка, очередь песен, журнал решений.

Запуск: `npm run dev`, затем http://localhost:5173. Опубликованная версия — GitHub Pages репозитория.

## Ссылки на сценарии

Адрес вида `#этап/сценарий/шаг` открывает сценарий сразу; шаг — номер или `end`.

| Этап | Сценарий | Что показать |
| --- | --- | --- |
| Сбор треков | `#intake/intake-batch` | Пачка из 10 песен, чистка тегов, вопрос только про непонятное, замена большого файла |
| | `#intake/intake-duplicates` | Чужой дубль принят молча, свой повтор и битые файлы отклонены |
| | `#intake/intake-close/end` | Отчёт организатора: пулы, достаточность, решения по недобравшим |
| Жеребьёвка | `#draw/draw-pairs` | Сетка 19 игроков, карточка соперника с контактом, судья, перенос срока |
| | `#draw/draw-decline` | Судья отказался — выбирают другого |
| Отборочный матч | `#match/quick-win` | Судейская панель, 5 треков, подтверждение результата |
| | `#match/qualifier-tie` | Ничья 2,1 : 2,1 и дополнительные треки до разрыва |
| | `#match/undo-audio-error-pause` | Отмена, ошибка аудио, пауза |
| | `#match/songs-exhausted/end` | Остановка только при нехватке песен |
| Финал | `#final/final-quarter` | Пары на сцене, очередь песен с пропуском песен пары |
| | `#final/final-threshold-tie` | 9,3 : 9,3 — победа только после закрытия трека |
| | `#final/final-offline` | Офлайн-комплект (CSV скачивается) и результат с бумаги |

Порядок для короткого показа на 10 минут: обзор → `intake-batch` → `intake-close/end` → `draw-pairs` → `qualifier-tie` → `final-quarter` → `final-offline`.

В любой момент можно нажать «✋ Вручную» или любую кнопку в чате — история продолжится от текущего шага. Это удобно для вопросов «а что если…».

## Что в демо упрощено

- Нет Telegram, базы и файлов: состояние живёт в браузере, аудио не проигрывается.
- Обработку файлов (ffprobe/ffmpeg) изображает кнопка «⚙️ Обработать»; битыми считаются файлы, помеченные так в каталоге.
- Пересланная пачка приходит одним событием; в Telegram каждый файл — отдельный update, адаптер соберёт их по media_group_id.
- Фоновые участники «уже сдали» песни, а в финале сами отмечают готовность и подтверждают результат.
- Этапы показаны на общем составе, но независимо друг от друга: жеребьёвка не берёт пулы из сбора, финал — финалистов из отбора.
- Знакомство с песнями через судейство учитывается при выдаче (`knownByPlayers` в сессии матча), но в демо-данных таких связей нет.

## Параметры демо

| Параметр | Значение | Где менять |
| --- | --- | --- |
| Песен на участника | до 10 | `DEFAULT_INTAKE_RULES` в `src/domain/submission/intake.ts` |
| Песен финалу | ~120 (7 матчей × 15 + 15) | `DEFAULT_FINAL_TARGET` в `src/domain/submission/pools.ts` |
| Отборочный матч | 5 треков, ничья до разрыва | `QUALIFIER_RULESET` в `src/domain/match/ruleset.ts` |
| Финал | до 9,0, лимит 20, ничья до разрыва | `FINAL_RULESET` там же |
| Очки | исполнитель 0,9, название 1,2 | там же |
